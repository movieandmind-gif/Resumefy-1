1. Термины и определения

Для целей настоящего Соглашения используемые термины имеют следующие значения, единые для всего комплекта документов Resumefy:

  1. Сервис (Resumefy) — программа для ЭВМ в форме бота мессенджера Telegram, обеспечивающая автоматизированный анализ резюме и описаний вакансий с использованием искусственного интеллекта.
  2. Владелец — Кириллов Кирилл Николаевич, физическое лицо, применяющее специальный налоговый режим «Налог на профессиональный доход» (самозанятый), являющееся правообладателем и администратором Сервиса.
  3. Пользователь — физическое лицо, достигшее 18 (восемнадцати) лет, осуществившее доступ к Сервису через свою учетную запись Telegram и принявшее условия настоящего Соглашения.
  4. Материал Пользователя — файл резюме в формате PDF или DOCX, изображение резюме либо текст описания вакансии, направленные Пользователем Сервису для анализа.
  5. Результат анализа — сформированный ИИ-моделью структурированный отчет, включающий оценку, сильные и слабые стороны, рекомендации и (при наличии текста вакансии) анализ соответствия.
  6. ИИ-модель / Модель — используемая Сервисом языковая модель искусственного интеллекта OpenAI GPT-4o, к которой Сервис обращается посредством программного интерфейса (API) компании OpenAI, L.L.C.
  7. История анализов — совокупность сохраненных Сервисом сведений о ранее выполненных анализах Пользователя в объеме, установленном Политикой хранения и удаления данных.
  8. Стороны — совместно Владелец и Пользователь.

Термины, не определенные в настоящем разделе, используются в значении, придаваемом им действующим законодательством Российской Федерации и иными документами комплекта Resumefy — Политикой обработки персональных данных, Политикой конфиденциальности, Правилами использования сервиса, Согласием на использование искусственного интеллекта.

3. Порядок использования Сервиса

  1. Доступ к Сервису осуществляется через мессенджер Telegram по идентификатору бота, указанному Владельцем в открытых источниках.
  2. Для получения Результата анализа Пользователь направляет Материал Пользователя одним из поддерживаемых способов: файл в формате PDF, файл в формате DOCX, изображение резюме либо текстовое сообщение с описанием вакансии.
  3. Обработка Материала Пользователя осуществляется по следующей технологической схеме: получение файла или текста → конвертация в текстовый формат (для PDF, DOCX и изображений) → передача текста ИИ-модели через API OpenAI → получение и структурирование Результата анализа → направление Результата анализа Пользователю → удаление исходного файла и извлеченного текста.
  4. Исходные файлы Материалов Пользователя и извлеченный из них текст не сохраняются Сервисом после завершения анализа. Подробный порядок хранения и удаления данных установлен Политикой хранения и удаления данных (документ 7 комплекта).
  5. Пользователь вправе в любой момент удалить сохраненную Историю анализов через функцию «Очистить историю» в интерфейсе бота. Удаление истории необратимо и не может быть отменено ни Пользователем, ни Владельцем.
  6. Сервис предназначен исключительно для лиц, достигших 18 лет. Направляя Материалы Пользователя, Пользователь подтверждает достижение указанного возраста.
